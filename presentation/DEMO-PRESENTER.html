Q&A prep — one line, then back to the benefit

  • “Is it secure / who can see what?”
    Role-based: employees see only their own claims; approvers see their queue; admins configure policy. Access via SAP’s standard identity (XSUAA).
  • “What happens when tax rates or limits change?”
    A configuration change in the Policy screen. No development, no redeploy of logic.
  • “Can it handle more countries?”
    Yes — routing, tax and limits are config-driven; adding a country is configuration, not a rebuild.
  • “How much to run it?”
    Standard SAP BTP; running cost is a sizing setting. Exact numbers come with the rollout plan.
  • “Is the data trustworthy?”
    Employee data comes from our live org directory (single source of truth); every change is audit-logged.
  • “How far along is it?”
    Working prototype deployed on BTP — the full claim-to-approval journey for UK and India, with automated tests.
